mm2-geo

Geometry-guided band sizing with a score certificate: faster minimap2 gap filling that preserves its gap scores

Geometry-guided band sizing for minimap2's gap filling. Each gap between chained anchors gets a band sized from its own geometry; in the default certified mode a band is accepted only when a score bound proves that no wider band could score higher, so every gap keeps minimap2's alignment score while the dynamic programming (DP) does less work.

The problem: one band for every gap

minimap2 aligns a long read by chaining exact-match anchors and then filling the gap between consecutive anchors with banded affine-gap DP (the ksw2 kernel). The band width is one global setting derived from -r: for the long-read presets (map-hifi, map-ont, map-pb) it is \(b_{\max} = 30{,}001\). Most gaps need far less: two anchors a few hundred bases apart, with a handful of small indels between them, are aligned correctly inside a narrow diagonal strip.

mm2-geo is minimap2 v2.30 with a compact, runtime-gated change in align.c. It keeps minimap2's seeding, chaining, scoring, ksw2 kernel and z-drop logic. It changes only how wide a band each gap is given, and when a narrow band is accepted.

The geometry of a gap

Two consecutive anchors fix a gap of query length \(q\) and reference length \(t\). Every end-to-end path through the gap's DP matrix starts on the main diagonal and ends at off-diagonal displacement \(q-t\). The drift \(d=|q-t|\) (written \(|\Delta q-\Delta r|\) in the paper) is therefore a hard lower bound on the band.

Lemma (geometric lower bound). Every alignment of the gap from \((0,0)\) to \((q,t)\) ends at displacement \(q-t\); a band of half-width below \(d\) cannot contain any end-to-end path.

mm2-geo starts each gap at \(b=\min(d+m,\,b_{\max})\): the drift the endpoints force, plus a margin \(m\) (default 20) for local wobble such as a compensating insertion–deletion pair.

The band only has to cover the displacement the endpoints impose (the drift \(d\)) plus a small margin; minimap2 gives every gap the same \(b_{\max}\).

Two acceptance tests

After the DP fills the band \(b\), mm2-geo must decide whether \(b\) was wide enough. The two modes answer this differently.

Certified mode default

Accepts the band only if the best in-band score \(S_b\) is at least an upper bound \(U(b)\) on the score of any path that leaves the band. Otherwise it computes the smallest band \(b^{*}\) the bound can certify and realigns there, then tests again (at most at \(b_{\max}\), where the computation is minimap2's own).

Each gap therefore receives minimap2's score. Read-level differences can only be equal-score alternative tracebacks.

The case the heuristic test misses: the in-band path never touches the band edge, so \(E<b\) accepts it, although a better path exists outside. The certified test compares scores, so it detects this case.

The score certificate

Let \(a\) be the match score and \(g(l)=\min(q_1+l\,e_1,\;q_2+l\,e_2)\) minimap2's dual-affine cost of a gap of length \(l\) (\(q_i\), \(e_i\): the -O, -E values).

Proposition (score certificate). Every path of the gap that leaves the band \(|i-j|\le b\) scores at most $$U(b)=a\left\lfloor\frac{q+t-L}{2}\right\rfloor-g(b+1)-g(b+1-d),\qquad L=(b+1)+(b+1-d).$$ Hence, for \(b\ge d\), if the optimal in-band score satisfies \(S_b\ge U(b)\), no band wider than \(b\), up to \(b_{\max}\), yields a higher-scoring alignment.

Why it holds. A path that reaches displacement \(b+1\) and ends at net displacement \(d\) inserts at least \(b+1\) bases and deletes at least \(b+1-d\) (the mirror case costs more). Those indels use up \(L\) of the \(q+t\) positions, which leaves at most \((q+t-L)/2\) aligned pairs, each worth at most \(a\). Splitting indels into several runs only adds opening costs, because \(g\) is subadditive, so the indels cost at least \(g(b+1)+g(b+1-d)\).

What happens to a gap

  1. One-gap shortcut (\(d\le 32\)): the best alignment with at most one indel of length \(d\) is found in \(O(q+t)\) by sliding the indel along the gap. It is accepted without DP when it beats the analogous bound on all alignments with two or more indels.
  2. First band \(b=\min(d+m,b_{\max})\). For gaps of 256 bp or more it is first scored without traceback (score-only pass), so that the first band is traced back only if it passes the test.
  3. Test \(S_b\ge U(b)\). Because \(U\) is non-increasing in \(b\), a failing gap is not doubled blindly: mm2-geo computes the smallest \(b^{*}\) with \(U(b^{*})\le S_b\) and realigns at \(b^{*}\), then tests again (ksw2's banded score is not strictly monotone in \(b\), and 0.1–1.7% of the widened chr22 gaps need another realignment).
  4. Traceback check. The score of the returned CIGAR is recomputed (a linear pass) and must equal \(S_b\); otherwise the gap is realigned with \(b_{\max}\).
  5. minimap2's own CIGAR-based z-drop test then runs afterwards, unchanged.

Every accepted band lies inside minimap2's band and carries a proof that minimap2's wider band would not score higher, so the certified gap score equals minimap2's. On chr22, the shortcut or the first band settles 97.5% of the gaps on HiFi and 89.8% on ONT; CLR, with its higher error rate, needs the realignment at \(b^{*}\) for 57% of gaps. Fewer than 0.01% of gaps fall back to minimap2's own band, and the DP still evaluates 1.15–1.73× fewer cells than minimap2.

The DP stage itself becomes 1.16–2.6× faster in the certified mode and 1.6–2.1× in the heuristic mode. The rest of the run is unchanged, so the end-to-end gain follows the share of run time spent in DP.

The heuristic mode changes small-variant F1 by at most 0.0011 in the GIAB high-confidence regions, but over the whole of chr22 it changes 6–8% of the small-variant and SV calls, mostly outside those regions. Use the certified mode wherever lower-scoring alignments must be excluded and minimap2's gap scores preserved, for example for structural-variant or repeat analyses and in validated pipelines.

Build and use

git clone https://github.com/genpat-it/mm2-geo && cd mm2-geo
make && cp minimap2 mm2geo

./mm2geo -ax map-hifi ref.fa reads.fq > out.sam                        # MM2_GEO unset: stock minimap2 output
MM2_GEO=1 ./mm2geo -ax map-hifi ref.fa reads.fq > out.sam              # certified mode (recommended)
MM2_GEO=1 MM2_GEO_FAST=1 ./mm2geo -ax map-hifi ref.fa reads.fq > out.sam  # heuristic mode

With MM2_GEO unset the executable produces alignment records identical to minimap2 v2.30. geo.patch applies the change to a stock minimap2 v2.30 tree (align.c only), and geo_mm2fast.patch ports both modes to mm2-fast (commit 14fe36c), where the certified mode is identical to mm2-fast and 1.08–1.17× faster than it on chr22. The short-read (-ax sr) and spliced paths are unaffected.
